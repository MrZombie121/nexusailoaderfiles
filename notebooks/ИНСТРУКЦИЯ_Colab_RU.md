# Инструкция по запуску NexusAI в Google Colab

Ноутбук `NexusAI_Colab_RU_EN.ipynb` предназначен для обучения модели на трёх двуязычных датасетах, проверки ответов в чате и последующего дообучения.

## 1. Открытие ноутбука

1. Откройте [Google Colab](https://colab.research.google.com/).
2. Выберите **File → Upload notebook**.
3. Загрузите файл `notebooks/NexusAI_Colab_RU_EN.ipynb`.
4. В меню **Runtime → Change runtime type** выберите GPU.

Для модели 300M желательно использовать T4 или лучше. Модели 1B–6B требуют гораздо больше видеопамяти; их рекомендуется дообучать с готовых весов, с уменьшенным batch size и mixed precision.

## 2. Подключение Google Drive и GitHub

В первой ячейке:

1. Запустите ячейку.
2. Разрешите доступ к Google Drive.
3. Замените значение:

```python
REPO_URL = 'https://github.com/OWNER/NexusAIprog.git'
```

на настоящий URL GitHub-репозитория проекта.

После выполнения проект будет находиться в `/content/NexusAIprog`.

## 3. Подготовка датасетов

Ноутбук не скачивает датасеты из Hugging Face. Он использует уже подготовленные файлы внутри проекта:

```text
/content/NexusAIprog/datasets/processed/
├── code.jsonl
├── math.jsonl
└── conversation.jsonl
```

Перед загрузкой проекта в GitHub положите эти файлы в `datasets/processed`. Если проект уже клонирован в Colab, их можно скопировать вручную:

```python
!cp /content/drive/MyDrive/nexus_datasets/*.jsonl /content/NexusAIprog/datasets/processed/
```

После выполнения ячейки проверки ноутбук должен вывести:

```python
Используются датасеты: /content/NexusAIprog/datasets/processed
```

## 4. Обучение модели

В интерактивной ячейке выберите:

- размер модели: `100M`, `300M`, `1B`, `3B` или `6B`;
- количество шагов;
- путь к датасетам.

Для первого запуска рекомендуется:

```text
Модель: 300M
Шаги: 100–1000
Данные: /content/NexusAIprog/datasets/processed
Готовые веса: пусто
```

Нажмите **Обучить / дообучить**.

Чекпойнты появятся в:

```text
/content/NexusAIprog/checkpoints/
```

Главный файл модели:

```text
checkpoints/latest.pt
```

После обучения скопируйте папку `checkpoints` на Google Drive, чтобы не потерять её после завершения сессии Colab.

## 5. Тестирование в чате

В поле **Запрос** введите текст на русском или английском языке и нажмите **Ответить**.

Ноутбук использует:

```text
checkpoints/latest.pt
```

Поэтому сначала нужно успешно выполнить хотя бы несколько шагов обучения.

## 6. Дообучение готовых весов

Для дообучения:

1. Выберите тот же размер архитектуры, с которым были созданы веса.
2. В поле **Готовые веса** укажите путь к `.pt`-файлу, например:

```text
/content/drive/MyDrive/nexus_models/300M/latest.pt
```

3. Укажите новые данные и количество шагов.
4. Нажмите **Обучить / дообучить**.

Результат будет сохранён как новая версия в `checkpoints/latest.pt`. Перед запуском рекомендуется скопировать старую папку `checkpoints` в отдельный каталог на Drive.

Важно: веса модели 300M нельзя загрузить в конфигурацию 1B, 3B или 6B. Размер выбранной конфигурации должен совпадать с размером исходных весов. Также должен совпадать словарь токенизатора `datasets/tokenizer/vocab.json`.

## 7. Если Colab прервал работу

После повторного подключения:

1. Снова подключите Google Drive.
2. Клонируйте проект.
3. Укажите сохранённый путь к датасетам.
4. Укажите путь к последнему чекпойнту в поле **Готовые веса**.
5. Продолжите обучение.

Не закрывайте вкладку Colab во время обучения и периодически сохраняйте `checkpoints` на Google Drive.

## 8. Частые ошибки

### `FileNotFoundError: requirements.txt`

Убедитесь, что выполнена ячейка клонирования проекта и текущая папка — `/content/NexusAIprog`.

### Несовпадение размеров весов

Выбран неправильный YAML-конфиг. Для чекпойнта 300M выбирайте `300M`, для 1B — `1B` и так далее.

### Не хватает видеопамяти

Уменьшите batch size в YAML, увеличьте `gradient_accumulation_steps` или используйте меньшую модель.

### После перезапуска пропали результаты

Сохраните `checkpoints`, `datasets/tokenizer` и конфигурацию на Google Drive до завершения сессии Colab.
